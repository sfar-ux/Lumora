# Lumora — Immersive University V1

An original, Zero-University-inspired immersive education landing page.

## Stack

- Next.js
- React + TypeScript
- GSAP + ScrollTrigger
- Lenis
- Three.js + React Three Fiber
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Customize

Main page:
`components/Experience.tsx`

Styles:
`app/globals.css`

The 3D hero is procedural, so no external 3D asset is required.
